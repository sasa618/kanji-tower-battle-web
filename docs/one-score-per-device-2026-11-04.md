# 全国ランキングを端末ごとに1件にする（2026年11月4日）

同じ人の記録がランキングに何件も並ぶのをやめ，端末ごとに1件だけ残すようにした．本人の指示で，この作業はAI（Claude）が担当した．

## 仕組み

- 端末は11月3日から記録に付けている `client`（端末識別子のハッシュ）で見分ける．移行 `0006_one_score_per_client.sql` が，既にある記録のうち端末の分かるものを端末ごとに最も良い1件（総画数，次に高さ，字数，先着の順）だけ残して消し，`client` が空でない行に一意索引を張る．11月3日09時より前の記録は端末が分からないため，そのまま残る（90日で消える）．
- `POST /scores` は，同じ札（セッション）の再送なら前と同じ順位を返し，別の内容なら409で断る（従来どおり）．その上で端末の記録を調べ，今回の記録のほうが良ければ古い記録を消して入れ替え（1つのバッチ＝トランザクション），劣るなら残っている記録の順位を `kept:true` 付きの200で返す．記録を入れ替えてから10秒以内の再送は429で断る．
- 端末ごとの「1分6件」の送信制限は，1件しか残らない方式では数えられないため，上の10秒の制限に置き換えた．
- 置き換えはサーバー側で行うので，ゲームの画面は変えていない．送った記録が残っている記録に劣るときも，ゲームは「送信済み」として扱い，返ってきた（残っている記録の）順位を表示する．

## 確認

`npm run check` と `npm test`（122件）が通る．追加した試験は，良い記録で置き換わり一覧が1件のままになること，劣る記録が残っている記録の順位を返すこと，10秒以内の再送が429になること，別の端末の記録は別に数えられること，移行が端末ごとの最良の1件以外を消し端末の分からない行は残すこと，である．
