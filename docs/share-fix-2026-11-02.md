# X共有の復旧（2026-11-02 JST）

## 確認した原因

画像付き共有用のWorkerがHTTP 429 / Cloudflare Error 1027（プランの利用上限）を返していた。従来の共有処理は画像作成・アップロードに失敗すると予約した空タブを閉じ、投稿リンクを残さなかった。以前の記録で塔の画像がない場合やオンライン機能を無効にしたビルドも共有できなかった。

## 修正

- 共有操作時に、得点・ハッシュタグ・公開ゲームURLを含む投稿リンクをすぐに表示。
- 画像を用意できたら画像付き共有URLへ切り替える。投稿画面は表示したリンクをタップして開くため、非同期処理後のポップアップに依存しない。
- 通信エラー・フォント読み込み失敗・15秒の待ち時間超過では、文字とゲームURLの共有を維持。
- 保存済みの共有URL・以前の記録・図鑑の共有でも、別タブを開けない場合に使えるリンクを表示。
- 図鑑で別の文字を選ぶと前の文字の投稿リンクを消す。

## 検証

- 型検査、ビルド、自動テスト99件が成功。
- 画像付きURL成功、HTTP 429/503/507相当の失敗、フォント失敗、処理停止、ポップアップ拒否の回帰テストを追加。
- ローカルの実画面で通信失敗後のリンクをクリックし、得点と公開ゲームURLを保持したXのログイン画面へ遷移することを確認。実際の投稿とスマートフォン実機での確認は行っていない。

この修正はCloudflareの利用上限そのものを解除しない。上限に達している間は画像付き共有と全国ランキングが利用できない場合があるが、文字とゲームURLの共有はWorkerに依存しない。
