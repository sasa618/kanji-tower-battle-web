## ランキングAPIの要求数とD1読み取りの削減（2026-11-02）

11月1日はD1の日次読み取り上限に続き，Workerの無料枠（1日10万要求）も超過して429（Cloudflare error 1027）になった．コードを読み直した範囲では，クライアントに自動の再試行・定期取得はなく，1プレイあたりの要求は約3.5件（/sessions・/eventsのPOSTと，それぞれのCORSプリフライト）で，6,000プレイ/日なら約2.1万件である．超過の経路はログが無効で特定できなかった．この見直しはAI（Claude）が担当した．

次の4点を入れた．利用者から見える動きは変えていない．

1. POSTの本文を `text/plain` で送り，CORSのプリフライトをなくす（約2割の要求削減）．Workerは `application/json` と `text/plain` の両方を受け付けるので，古いビルドの端末からの送信も通る．Originの確認は従来どおりである．
2. Workers Logsを1割の標本で有効にし，要求の内訳を調べられるようにする（無料枠は1日20万件，保存3日）．
3. 送信直後の順位計算で数える上位行を1000行までにし，それより下は「1000位より下」と表示する．スコアが増えても1回の送信で読む行数が増えない．
4. 障害時の抑制．通信失敗・429・502〜504の後は，端末側の全要求を15秒から最大10分まで倍々に間を空けて止める（成功または4xxの応答で解除）．Workerの503には `Retry-After: 15` を付ける．回復直後は少し待たされることがある．

結果・自己ベストの共有で画像の送信に失敗したときに画像なしで投稿できるリンクを出す修正は，同じ時刻に別の作業（e3b751c，`src/share-intent.ts`）がmainへ入れていたため，こちらで用意した同じ趣旨の変更は取り下げ，その版を採用した．

PCでは，盤面を押した位置へ字が移動し，離すと落下する．盤面右上の「回転」ボタンのすぐ外を押してしまうと，字が盤面の右端へ移って台の外に落ち，ゲームが終わるという報告があった．マウスの押下に限り，`.board-actions`（回転と一時停止のボタン）の周り28px以内の押下を無視するようにした（`src/input.ts` の guard）．指とペンの操作は変えていない．利用者が盤面の端を狙って落とす操作は，ボタンの周りを避ければ従来どおりできる．
